# ABADÁ Capoeira Belgique

Next.js 14 + Tailwind CSS site for ABADÁ Capoeira Belgique with Mestre Tigre.

## Features
- Next.js 14 with App Router
- TypeScript
- Tailwind CSS with dark mode
- Framer Motion animations
- next-intl (FR/EN/PT)
- Real images from capoeirabelgique.be
- Azure deployment ready

## Installation
npm install
npm run dev

## Build
npm run build
npm start
